سلام! اسمت چیه؟

به جای نام کاربری، فقط یک نام نمایشی وارد کن — همین نام برای طرف مقابل نمایش داده میشه. چت دوطرفه، متن + فایل (هر فرمتی).

با ساخت یک کد/لینک میگیری و برای دوستت میفرستی. او با پیوستن وصل میشه — بدون ثبت نام.

پیامی هنوز نیست — لینک رو برای دوستت بفرست تا وصل بشه.
همه فرمتها — عکس، ویدیو، pdf، zip، md، html، هر چی — مستقیم P2P بین دو مرورگر. فایلهای خیلی بزرگ (۵۰MB+) ممکنه کند باشه.
ساخته شده برای GitHub Pages — فقط index.html را در ریپو بذار و Pages را روشن کن. PeerJS Cloud (رایگان) برای برقراری اتصال استفاده میشود؛ پیامها P2P و ذخیره نمیشوند.
